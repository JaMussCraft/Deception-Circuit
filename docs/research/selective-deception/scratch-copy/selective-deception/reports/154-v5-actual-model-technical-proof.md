The proof performs:

1. Compare actual model geometry to the frozen manifest and require exactly the five actual enabled gate families: attention blocks, heads, neurons, MLP hidden, MLP output. Extra embedding/layer/MLP-block gates fail closed.
2. On that actual model, apply explicit full support and each of the four finest knockout complements, then compare every live gate bit to the expected support. Check each removed head contains all head dimensions; all nonselected/coarse/MLP support remains open. Record actual support digests and removed query-head counts for all five states. Missing gates/layers or width mismatches fail before a forward pass.
3. On fixed clean IDs `[1,2,3,4]` and corrupt IDs `[4,3,2,1]`, compare two full-vocabulary last-token vectors: existing `open_all_gates` versus explicit all-ones support. Both use the same existing node model, weights/dtype, input/donor tensors and dual-stream forward path. Cached mode uses fresh paired DynamicCache objects and the same prefill mask/positions as generation; uncached mode uses the corresponding uncached dual-stream path. No plain-model/cross-path comparison, labels, generation, tolerance tuning or efficacy outputs are introduced.
4. Require finite **bit-identical** vectors of shape `[1,model.config.vocab_size]`. Record full vector hashes, exact result, maximum difference, model class/config name, geometry, dtype/device, manifest/source/input digests and Torch version. No semantic prediction is used.
5. Restore original gate parameter tensors, final-mode flags and all module training flags in `finally`, on success and failure. Session mask bookkeeping is not modified.
