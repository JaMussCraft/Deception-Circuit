# Bounded final WikiText assessment caller

2026-10-19. Implementation is external to the frozen `selective-wikitext` worktree: `analysis/evaluate_wikitext_final.py`, with CPU tests in `analysis/tests/test_evaluate_wikitext_final.py`. The reviewed production source tree was not edited. No pretrained model weights, actual heldout model outputs, GPU, Slurm submission, API, network, git, or subagent was used. Only random tiny CPU model/logit fixtures ran.

## Shared root finality receipt

Agreed with the native-assessment caller. The root-owned JSON has `version:1`, `finalists_frozen:true`, `expansion_decision:"union_only"|"all_heads_complete"`, `selection_basis:"SDR_WikiText_validation_only"`, `no_test_based_selection:true`. `finalists` contains exactly H/W/HW for union, plus H/W/HW for all when expansion completes. Every entry has `arm`, `space`, `status:"admissible"|"failed_frontier"`, and absolute `manifest_path`, `checkpoint_path`, `export_path`, `run_identity_path` with their respective `_sha256` fields. The run-identity JSON is exactly the selected export's `provenance` object, serialized as JSON; it need not be generated by a new inference.

The WT caller freezes its own request binding the raw shared receipt SHA, canonical protocol and WT-manifest SHAs, complete reviewed helper source inventory hash, evaluator bytes, and canonical SDR data directory. Native caller owns its separate request. Root must finish actual own-arm validation selection across rho and the conditional expansion decision before freezing this shared receipt. The WT caller performs no checkpoint ranking or adaptive choice; an unsuccessful arm remains a reported `failed_frontier` finalist.

## Commands for root

Run CPU preparation only after the actual finality receipt and selected artifacts exist. Paths here are examples for root; no final receipt/request was manufactured by the worker.

```bash
WT_CALLER=/projects/beto/swong2/Alignment/.scratch/selective-deception/analysis/evaluate_wikitext_final.py
WT_STUDY=/projects/beto/swong2/Alignment/.scratch/selective-deception/sparse-wikitext-v2
python "$WT_CALLER" --prepare --selection-receipt "$WT_STUDY/final-selection-receipt.json" --request "$WT_STUDY/final-wikitext-request.json"
python "$WT_CALLER" --dry-run --request "$WT_STUDY/final-wikitext-request.json"
```

The payload inside a separately root-reserved Slurm GPU allocation, in the **same package/GPU/model/source runtime as training**, is:

```bash
python "$WT_CALLER" --run --request "$WT_STUDY/final-wikitext-request.json" --output-dir "$WT_STUDY/final-wikitext" --data-dir /projects/beto/swong2/Alignment/Deception-Circuit/data/datasets/sdr
```

Model snapshot/revision/settings come from bound training identity, never a new caller model choice. `_identity` rehashes actual snapshot files and inventories helper source, packages, hardware and numerical path; its retained baseline fingerprint must equal training. All finalists must share that retained identity. This deliberately requires matching runtime even though test references are newly generated. Changing runtime requires a separately reviewed policy rather than silently comparing mismatched interventions.

## Bounds, validity and output

The caller uses all 16 canonical official-test windows, each128 tokens/127 predictions, frozen different-document nonself donors, full-vocabulary KL, and corpus recipient targets. Every finalist has16 windows/2032 predictive positions, including failures in denominators. It uses reviewed `_runtime`, `_wt_logits`, `_restore`, `configure_candidate_gates`, `export_binary_masks`, and WT cache/loss primitives via the explicit worktree path. Every checkpoint is digest/fingerprint verified and must recreate the exact bound export before any test reference or score. All noncandidate and nonattention gates are hard-open; evaluation is deterministic binary removal, with frozen weights and zero optimizer steps.

Fresh CPU FP32 full-vocabulary reference shards are created only for test. Before scores, all-open self-donor and nonself-donor **entire log-probability tensors must match exactly**. One current reference block is staged on GPU. No training/validation reference cache is reused or modified. The request and actual runtime bind the new cache fingerprint, whose block digests are included in final output. Primitive FP32 NLL accumulation can produce tiny all-open NLL rounding residuals against the reference's double sum; exact distribution identity, rather than a rounded scalar zero, is the strict control.

`result.json` is atomically published only after the full all-open baseline and every frozen finalist completes, and after revalidating frozen file bindings. It includes per-window KL/NLL delta, aggregate predictive KL/NLL/base-NLL/NLL delta/perplexity ratio, window-mean NLL hinge, paired-window mean/SE/range/improved/worsened/tied counts, counts, checkpoint/export/receipt/request/cache/runtime identities, measured model-load/reference/finalist/total timing, CPU RSS, peak allocated/reserved CUDA memory and reference bytes. No independent confidence claim is made from the16 structurally fixed windows.

There are96 forward calls for three finalists,144 for six:48 for self-reference creation, exact all-open donor checks and all-open scored replay, plus16 per finalist. Root must price/reserve this payload using measured throughput. No GPU timing or memory claim was invented. The one-shot output uses an exclusive writer lock and exclusive `started.json`; interrupted runs cannot automatically resume or reuse partial references. A technical failure leaves no completed `result.json`; root decides any charged recovery.
