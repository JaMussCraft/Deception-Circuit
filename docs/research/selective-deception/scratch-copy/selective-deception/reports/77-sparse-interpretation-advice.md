## What the fixed evaluations can establish

- **Optimization result:** within the fixed model, seed, update budget, candidate space and nonself interchange policy, a learned binary mask can or cannot attain the specified SDR label-suppression/preservation tradeoff. Own-arm admissibility remains the selection rule. A useful W result with H loss is a useful W result with a disclosed cost. Neither failure after 512 updates nor all-head failure proves no sparse solution exists.
- **Transfer result:** paired intact versus masked native generations can show reduced raw false assertions under instructed lying, with the observed H retention and R compliance, conditional on the frozen H donor banks and alignment policy. Coherent D refusal is successful suppression; H/R refusal loses utility. Report all 16 rows, intact-to-masked transitions, ambiguity bounds and damage. This does not establish autonomous strategic-deception suppression.
- **Preservation result:** final WikiText quantifies predictive-distribution/NLL changes on 16 fixed windows (2,032 positions), not general language competence. Correlated token positions are not 2,032 independent experiments. Native H retention tests a narrow factual slice. Old R compliance of 0/16 warns that the fresh R baseline may be uninformative; if it again has zero capable rows, retention is undefined, not perfect. A few capable rows support only correspondingly limited retention evidence.
- **Comparison:** H/W/HW differences describe these fixed optimization procedures. One seed and unequal effective collateral gradients do not establish an intrinsically superior preservation objective. Validation selection over checkpoints/rhos makes validation improvement exploratory; final native/WT assessment is separate, but inspecting multiple finalists still does not license a confirmatory winner claim.

Freshness protects the declared statement/twin boundary, not globally unseen entities, relations or model pretraining exposure. False statements are all city-in relations; the true side mixes two city-in and six name/category claims. Report those strata, without interpreting truth-specific effects independently of form. Failure of any stronger behavioral criterion does not erase a surrogate-level result or reopen frozen selection.

## The two consequential missing controls

**Donor content.** Independent valid donor execution removes an implementation artifact, not the scientific ambiguity of replacement. A closed head can import a donor judgment, refusal tendency, topic or answer-routing signal. The balanced source-truth assignment and independent blind donor-quality annotations enable descriptive diagnostics: actual donor judgment versus recipient truth/encoded target, shared assertions, refusal, mapping coverage and terminal-held steps. They do not causally isolate answer transfer, since each recipient has only one donor and source truth need not equal the generated judgment. A donor-dependence pattern limits the mechanism claim; it does not negate coherent behavioral suppression. Absence of a visible pattern in four-row truth cells is weak evidence against transfer.

**Matched random heads.** Intact comparison demonstrates an intervention effect, not unusual specificity of the selected sites. Earlier core/random zero results involve different masks, examples and replacement semantics, so cannot supply this control. A relevant baseline has the learned mask's exact removed count and per-layer count, the same eligible candidate universe, nonhead openness, donor banks, alignment and decode. Draw without behavioral screening; allow natural overlap with learned heads and disclose constrained/degenerate layer choices. Excluding all learned heads changes the null. Compare the joint suppression/utility pattern, not D suppression alone.

Even favorable random and donor comparisons would identify a promising sparse intervention, not prove a dedicated deception module, necessity of those sites, or donor-independent removal. The current tranche can be reported soundly without either additional experiment by keeping this narrower language.

## One contingent diagnostic, not an expanded search

Only if a frozen finalist shows clear native D suppression without new false D answers or output damage, retains intact-usable H, and meets both H/WT preservation criteria, consider one bounded diagnostic. If R remains incapable, explicitly keep broad instruction-selectivity unestablished; this diagnostic may still clarify the narrower D/H effect. If no finalist has that pattern, stop at the frozen report; do not add controls to rescue it.

Freeze at most one qualifying finalist using a deterministic rule: smallest removed count, then fixed H/W/HW and union/all order. Label that choice outcome-contingent and the reused native slice exploratory. Freeze four size/layer-matched random masks before their outputs, plus one alternative donor permutation for the learned finalist. Construct the permutation structurally to reverse each recipient's original source-truth agreement while retaining nonself donors and the same donor inventory; never screen or replace donors by answer quality. Keep all prompts, alignment rules and generation settings fixed. Reuse authenticated banks and existing intact/original-finalist outputs.

Maximum new native workload: four random masks ×16×D/H/R plus one alternative-map finalist ×16×D/H/R = **240 completions, at most 61,440 generated tokens**. Evaluate the four random masks on the existing 16 WT windows as a supplementary collateral comparison. No refits, new prompts, alternate checkpoints, seed sweep, additional maps or automatic retries. A changed donor also changes content and positional coverage, so the second map probes robustness to donor assignment; it does not isolate pure answer-token transfer. Four random draws give descriptive context, not a calibrated claim of statistical rarity or a crossed mask-by-donor experiment.

Root should first price this from the actual final-evaluation throughput, including startup/replay/WT overhead. Proposed ceiling: **one additional reserved GPU-hour within the remaining 20-hour envelope**, zero APIs; if it cannot fit, defer and report the limitation. This is a contingent proposal, not a reservation or launch instruction. The currently frozen final assessments and authorized fits take priority. A positive diagnostic would justify discussing independent confirmation later, not silently extending this study.
