## Primary causal contrast and intervention definition

Use an isolated main-based HF driver because existing component knockout hardcodes item-swap donors and existing native path code assumes aligned prompt positions. Preserve frozen V5 input/model/tokenizer identities as data, while explicitly recording the new driver/backend/source.

**First intervention is readout-position-only:** replace selected query-head slices of the attention output-projection input at the recipient's last actual prompt token with the assigned independent neutral-H donor's own last actual prompt-token activation. This is an explicit functional readout correspondence, not a claim that unequal-length D/H prompts align token-by-token. Reuse one scenario-disjoint donor assignment across D/H/I/no-pressure and every compared state. Other heads, positions and MLPs stay open. This deliberately differs from V5's all-position replacement and free generation; measure its own aggregate effect before interpreting head decompositions.

For condition c, define m_c = logit(requested target) − logit(alternative), with true targets for H/no-pressure and the audited instructed targets for D/I. For head/set S, Δ_c(S)=m_c(full)−m_c(replacement S). Positive Δ_D reduces the instructed false answer; positive Δ_I harms benign inversion compliance; positive Δ_H/Δ_N harms truthful capability. **Primary deciding contrast is paired Δ_D(New30)−Δ_I(New30)**; the30-head map and seven conditional releases are exploratory decompositions. Report this contrast accompanied by both raw effects and H/no-pressure losses, accuracy transitions and margins. Never report only the difference or a ratio with a near-zero baseline. Positive D−I suggests differential mediation under these controls, not deception specificity. Negative/zero differences are informative mechanism results.

First-state budget: five aggregate anchors(full/New23/New30/OldD69/fixed random30),30 single-head replacements in otherwise intact model, and seven New30-minus-one-added-head releases. The latter are **conditional release effects**: the released head computes normally in its already perturbed upstream context. They are not cached-clean activation rescues, seven independent contributions, or a new seven-head circuit. Report all30 and allseven; no greedy removal, recomposed optimized mask, all-pairs head grid or new training.

Use developer16 to select any follow-up contrast by an explicit fixed rule, then evaluate it on untouched-by-selection validation16. Both partitions were exposed to prior V5 assessment and are mechanism development/validation, not pristine confirmation. Cluster paired uncertainty/resampling by scenario and show polarity/position strata; single-head effects need not add to the joint mask effect.

## Attention and at most three targeted follow-ups

Record baseline D/H/I attention for all30 heads on a deterministic eight-scenario SDR development subset, summarized over verified instruction/clause, fact/options and final-token positions. Attention is descriptive evidence only. If eager attention requires a backend change, establish same-backend clean/no-op identity and compare relevant baseline logits against the causal backend before combining readings. V5's node-model proof does not automatically validate this HF/eager path. GQA K/V effects concern shared groups; do not label them independent query-head K/V interventions.

After the first pilot, allocate **at most three explicit contrast pairs**, without a global path search:

1. **Donor-content contrast:** for aggregate New30, compare two predeclared independent honest-donor assignments whose construction labels agree/disagree with the recipient truth, keeping all recipient inputs fixed. Preserve scenario disjointness. A shift toward donor answers supports content injection/routing; label association alone does not isolate content from every other donor difference.
2. **Clean-output rescue:** pick the added head with largest positive development conditional D-release effect (fixed layer/head tie-break), and transplant its cached intact recipient output at the same readout position into the New30 run. Compare with New30/no-op and test D/I/H on validation. This is distinct from simply releasing its replacement; partial restoration is local rescue evidence, not whole-circuit sufficiency or unique necessity.
3. **One targeted path or position contrast:** only if explicit source/receiver token mapping is validated, test the single attention-supported instruction/clause→selected receiver hypothesis against a matched fact/answer source or sham. Hold other routes to their declared counterfactual values and record the isolation semantics. If mapping/receiver isolation is not ready, defer this contrast; do not use right-aligned overlap as causal alignment or compensate with an all-position grid.

Instruction machinery predicts similar D/I disruption; truthful knowledge loss predicts H/no-pressure damage; donor routing predicts donor-dependent output shifts. Refusal machinery cannot be diagnosed from two-label logits or attention alone: this pilot may motivate, but does not itself establish, a free-generation refusal mechanism. Do not relabel answer suppression as refusal or claim that attention to a clause proves semantic deception processing.
