CPU inspection of cached train rows0–34 showed exact level-one title form ` = Valkyria Chronicles III = \n`, subsection ` = = Gameplay = = \n`, and level-three ` = = = Music = = = \n`. Parser strips rows, treats rows beginning/ending `=` as heading-only, and recognizes a new article only when removing one outer `=` leaves nonempty text that neither begins nor ends `=`. Blank and heading rows are omitted; body rows are stripped and joined by two newlines. Each eligible article supplies its first full block only, with position0 replaced by BOS when supplied. Short articles are skipped; insufficient eligible articles fail. Content is never joined across articles. No generated outputs enter selection.

Manifest keys: `version,dataset,tokenizer_identity,block_size,pairing_seed,text_join_rule,bos_token_id,splits,manifest_hash`. Each split contains `source_path,source_sha256,n_blocks,blocks,donor_permutation,donor_permutation_hash`. Blocks contain `block_id,input_ids,attention_mask,input_ids_hash,doc_id,source_doc_index,content_hash`. Document identity is SHA256 of whitespace-normalized title; content hash covers the full joined article body; token hash covers selected BOS-replaced block. The validator rejects shared source paths/hashes, duplicated selected document IDs, selected cross-split document IDs/content hashes/token hashes, invalid tokens/masks/source ordering, bad permutations, self/same-document donors, and stale canonical hashes. One selected block per article ensures a nonself donor is a different document. All source file SHA256 values are verified before tokenization; only `Dataset.from_file` reads explicit local files. Canonical JSON binds dataset revision/config/version and every preprocessing/data field.

`iter_blocks` returns fresh CPU LongTensor copies and stable split-local donor data. Cache fingerprints bind manifest and root-provided complete reference identity. Per-block references contain FP32 CPU contiguous detached predictive log probabilities, Python float base NLL summed with float64 accumulation, input token hash, identity and payload digest. Same-directory temporary write+fsync+replace publishes under an exclusive writer lock; an existing final file is never overwritten. Failed writes remove temporary/lock files. Reads verify ownership, digest, finite values, dtype and shape; each read owns its storage. Cache references are not eagerly loaded by the module and no model context exists here.

`block_loss` validates geometry/device/finite values/token bounds/detached references, then accumulates FP32 KL(base||masked) and empirical NLL in32-position chunks across positions0..S-2. Both sums retain masked-logit gradients; reference tensors remain untouched. AtS128 the denominator is127. The module makes no scheduling, weight, hinge, gate, arm or selection decisions.
