## 3. Three collateral arms with explicit units

For each masked example define H truth nondegradation as `max(0, NLL_masked(y_H) - NLL_base(y_H))`. Let `K_H` be full-vocabulary `KL(P_base || P_masked)` averaged over the baseline-capable H training rows; let `N_H` be truth nondegradation averaged over **all** H training rows. Set `C_H = (K_H + N_H)/2`. Capability is frozen from the validated intact full-vocabulary truthful argmax, never a selection of evaluation rows. Report counts; if the capable set is empty, define `K_H=0` explicitly and report that absence rather than dividing by zero or silently switching to all-row wrong-answer KL. `N_H` remains defined. No former 60/119 H-capability or generated-headroom floor vetoes training under this amendment.

For WikiText let `K_W` be full-vocabulary `KL(P_base || P_masked)` averaged over every unpadded next-token prediction position in fixed windows. Let `N_W` be the **window-level** nondegradation hinge: compute each window's mean masked NLL minus its mean intact NLL on the actual corpus tokens, clamp at zero, then average windows. Set `C_W = (K_W + N_W)/2`. Token-level KL is nats/predicted token; H KL is nats/readout. Each term is normalized by its own declared observations, not by combined batch token count. Window-level NLL avoids requiring every unpredictable individual token to retain identical likelihood.

Use these three objectives with the same target, optimizer and removed-count coefficient:

- **H:** `T + C_H + rho * E[removed_heads]`.
- **W:** `T + C_W + rho * E[removed_heads]`.
- **H+W:** `T + (C_H + C_W)/2 + rho * E[removed_heads]`.

Averaging the combined collateral blocks keeps total nominal collateral weight at one instead of doubling it. It does not prove equal effective strength across tasks; report each raw component and its gradient contribution at smoke. Do not divide by intact collateral losses, which start at zero, or normalize adaptively by observed optimization success. No beta sweep. A pure corpus-NLL objective could reward changing the model instead of preserving its behavior, while KL alone cannot establish retained ability; this fixed combination and separate evaluation make their roles explicit.

Compute target and collateral means separately under the same gate-noise realization per optimizer update, including gradient accumulation. H and W data volumes must not silently reweight the objective. Frozen reference outputs have no gradients; base weights remain frozen; only eligible gate logits update.

Freeze **eight SDR pair presentations per optimizer update**, accumulated in the smoke-verified microbatch size. Normalize D/H sums over the entire eight-pair update (and its full capable-H count), not by averaging unequal microbatch means. Each W-enabled update additionally uses **one complete 128-token WikiText block**; a 32-block fixed-seed cycle repeats exactly 16 times across 512 updates. H-only omits W loss forwards; W-only may omit H loss forwards, but all arms share the identical D presentation order. The paired SDR sampler wraps across epoch boundaries without dropping the tail: with 119 pairs, 4,096 presentations comprise 34 full cycles plus 50 presentations of the next. Freeze permutation seeds/cycle ordering and resume position. No outcome-driven early stopping or midpoint cutoff; stop early only for numerical/resource failure, which is an incomplete run rather than a negative scientific result.

## 5. Small production grid and checkpoint rules

Default grid: **three arms × two count-based rho values `{0, 0.01}`**, one fixed seed, six runs. Rho zero is the explicitly unsparsified count-penalty comparator, not a promise of a sparse solution. All use identical target examples, candidate support, donor policies, data order, initialization and update/checkpoint schedule. Compare expected and actual removed **counts**, not fractions; retain these units on all-head expansion. No rho/seed additions based on interesting outcomes.

Retain AdamW learning rate 0.03, weight decay zero and the existing clipping. Initialize expected removal at approximately one with all deterministic gates open. A very short smoke is not an adequate optimization budget: with this initialization and learning rate, deterministic gates may need roughly 155 updates in the union or 231 in all-head space even under consistently directed Adam steps to cross the binary threshold. Freeze **512 optimizer updates and checkpoints every 64 updates** as the common initial costed schedule, subject to measured runtime, not a promise of convergence. Verify full training-set coverage and fixed balanced scheduling within that budget. If 512 updates cannot fit the tranche, root should cost a reduced **three-arm, one-rho 0.01** comparison before production; do not silently run an ineffectual handful of updates or choose which arm gets more optimization. Freeze the actual grid before seeing production outcomes.

For each run retain its deterministic checkpoint frontier. Evaluate **SDR D/H, WikiText and recoding/instructed-lying transfer in every arm**, including dimensions absent from its loss. Report the collateral dimensions absent from each arm’s objective as explicit out-of-objective outcomes; do not conceal them or use them as unannounced arm-specific vetoes. For economical generation, choose one checkpoint per arm from its fixed readout/LM validation frontier, then generate all three domains for all three finalists once. Freeze this selection rule before fitting: prefer checkpoints admissible under that arm’s own declared collateral constraints below; maximize D-surrogate reduction, then fewer removed heads, then earlier checkpoint; break rho ties deterministically. If an arm has none admissible, still report its best-D-surrogate checkpoint (same ties) as a failed frontier example rather than hiding the arm.

Arm-specific admissibility for finalist selection always requires nonzero binary removal and lower D suppression surrogate. The **H arm** additionally requires no net all-H truthful-argmax loss and no baseline-capable-H loss; the **W arm** requires held-out WikiText mean NLL increase at most `log(1.05)` nats/token (5% perplexity increase) and mean full-vocabulary KL at most **0.05 nats/token**; **H+W** requires both. H failure does not veto a W-arm checkpoint, and W failure does not veto an H-arm checkpoint. Preserve and report the joint D/H/W validation frontier for every arm, rather than hiding tradeoffs behind selection. These are conservative exploratory tolerances declared before outcomes, not universal utility thresholds. Evaluate all-H paired losses as well as aggregates. Record masked D label accuracy/probability so shifting into arbitrary vocabulary is visible.

Native assessment must use newly structurally fixed, semantically deduplicated statement clusters disjoint from the prior 16 development pairs; never train on or select masks from those prior outcomes. ## 6. Arm-specific useful findings, selective claims and all-head trigger

A **useful compact arm-specific restricted finding** is a deterministic binary mask removing **1–16 heads**, reducing intact validation D suppression surrogate by **at least 10%**, and satisfying its **own** arm-specific preservation constraints from section 5. These 16-head/10% values are pre-output engineering thresholds for deciding whether the restricted space yielded a worthwhile tradeoff, not significance tests. A W-only result meeting this definition remains useful even if H or recoding worsens: it directly answers the user’s requested W-only collateral question. Report those costs rather than erasing the result with a global H veto. A useful label-level result is not automatically selective generated-behavior suppression.

Separately, a result supports **advancing a selective-behavior hypothesis** only if a nonempty binary mask passes **both** H and WikiText readout/LM preservation criteria above regardless of its training arm, strictly reduces adjudicated false D generation on the frozen native assessment, introduces no false D answer on previously clear nonfalse rows, preserves every intact-usable matched H answer and every intact-correct recoding response, and introduces no empty/malformed/unusable or unresolved-ambiguous output on previously clear responses. Native D must have measured headroom and both benign generation controls must be interpretable; otherwise the behavioral criterion is unestablished. Report stratum counts and uncertainty. These are advancement/claim criteria, **never pretraining vetoes**.

A mask with better SDR label suppression but failing transfer is still an informative label-level result; report it without claiming selective generated-deception suppression. No candidate is called globally selective merely because the arm's own training collateral improved. A promising sparse mask would subsequently need a size/layer-matched random comparison and independent confirmation; this tranche is not that confirmation.

After the frozen restricted comparison is completed with valid finite losses, functioning gradients, correct hard-mask export and the planned update budget, **no compact arm-specific useful finding in any arm triggers one user-authorized all-attention-head expansion** of the same three-arm objective comparison. Failure of the stronger selective-behavior claim alone does not trigger expansion when an arm already supplies a compact, worthwhile label-level tradeoff. A larger-than-16-head or below-10% result is still reported, but does not satisfy this predeclared restricted-space criterion. Expand eligibility to all 1,024 attention heads, keep MLPs open, keep objective units/data/donor/seed/rho/checkpoint rules unchanged, and remeasure memory/step time if implementation geometry changes. Do not expand to rescue a code defect, invalid cache, absent data or an interrupted/unfunded training run; fix technical failures first. Expansion is a bounded candidate-space test, not proof that the union contains no solution.
