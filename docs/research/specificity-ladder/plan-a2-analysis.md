# A2 mask comparison and specificity ladder analysis plan

> **For agentic workers:** Use executing-plans task by task after lead review. Workers never run git; the orchestrator commits explicit files. This task writes the prospective analysis design only.

**Goal:** Compare all eighteen full A2 masks and test whether each task has a stable D-minus-I component set satisfying the unchanged A1 specificity rule.

**Architecture:** Normalize compact native mask exports into typed sets, freeze derived memberships without assessment outcomes, then score each per-seed difference through the existing pure ladder runner and metrics. Add a separate immutable A2 group/source contract around the unchanged frozen A1 assessment and donor design; do not impersonate the A1 selection artifact.

**Tech stack:** Existing Python, JSON, pytest, native `analysis.py`/`l0.py`, `component_analysis/specificity_ladder.py`, `ladder_metrics.py`, `ladder_design.py` and `ladder_pipeline.py`. No new service or model training in this plan.

**Spec:** [START.md](START.md), [spec.md](spec.md), [plan-a2.md](plan-a2.md), [plan-ladder.md](plan-ladder.md). START gates prevail. Choices explicitly labeled **lead proposal** below require orchestrator review before implementation/scoring; no full500-epoch scientific masks or A2 assessment outcomes informed these choices.

## Frozen set algebra and verdicts

For task t and seed s, let D[t,s] and I[t,s] be effective active component sets from the matched full500-epoch exports. Use repository component keys: a head `('head', layer, head)` and MLP block `('mlp', layer, 0)`. Typed components are disjoint; one block is one component rather than thousands of neurons or weighted parameters. These are the exact keys documented in `hooks.py` and emitted by `all_component_keys`; canonical serialized memberships retain them losslessly.

Let H(X) and M(X) select head and MLP keys respectively. Freeze, for every t,s:

- X[t,s] = D[t,s] minus I[t,s] (primary D-exclusive group).
- Y[t,s] = I[t,s] minus D[t,s]; B[t,s] = D[t,s] intersection I[t,s]; U[t,s] = D[t,s] union I[t,s].
- Primary training-seed core K[t] = intersection of X[t,42], X[t,1], X[t,123], diagnostic only. Also retain the union of the three X groups. Neither replaces any per-seed group or rescues a failed primary gate.

**Lead proposal: primary stability universe** is the mixed typed head-plus-MLP X set, matching the trained granularity. For each task, report the three individual pairwise Jaccards J(X42,X1), J(X42,X123), J(X1,X123), their minimum and all membership/counts. J(A,B)=|A intersection B|/|A union B| when the union is nonempty. Require all three values to be defined and >=0.5. Head-only and MLP-only pairwise tables are separate diagnostics; neither can replace a failing mixed-set result. Do not pool tasks or use a mean Jaccard that hides a failing pair.

Empty/empty Jaccard is null/undefined with `both_empty`; never impute1. Empty/nonempty is0. Thus an all-empty task has no informative stable exclusive set and cannot pass. Empty candidate groups stay in receipts and, if scored, use the empty-patch control path; they cannot pass necessity. Missing/invalid seeds yield `incomplete`, never a two-seed substitute.

For containment, c[t,s]=|H(D[t,s]) intersection H(I[t,s])| / |H(D[t,s])|. Report numerator, denominator, ratio and D-exclusive head count for each seed. START's head-containment result requires c>=0.90 on every seed with a nonempty D-head denominator. With no D heads, report `undefined/vacuous_no_D_heads`, not an informative90% finding; the task-level informative head-containment claim is unavailable if any seed is vacuous. Head containment and MLP exclusivity may coexist. Call this **head containment**, never whole-mask containment. Separately report MLP containment and exact whole-set subset flags, including vacuous flags. A task may meet both the head-containment result and the mixed-component specificity pass; these are distinct findings, not forced exclusive labels.

**Lead proposal: robust task pass** requires all of: valid complete three-seed mask provenance/export checks; all three primary Jaccards >=0.5; and all three X[t,s] groups individually passing the primary A1 rule on the unchanged assessment with complete assay controls, coverage and MMLU floor. All three per-seed specificity tests are required even if K is nonempty. Use the existing point-rule and separate uncertainty labels; an interval crossing a bound means uncertain specificity evidence even when the point gate passes. A task-level strong label additionally requires all three per-seed primary cells to be strong under the existing interval convention. Report all task results, without declaring a session-wide result from one successful task or cherry-picking seeds.

Evaluate every per-seed X group even when stability fails, if the frozen analysis budget permits. Instability already prevents robust pass, but effects remain informative. No assessment result may choose memberships, seeds, diagnostic core, task coverage or stopping order.

Publish numerator/denominator and per-stream gaps; nonfinite, nonpositive or epsilon-small aggregate or stream gaps are uninterpretable, never passing.
