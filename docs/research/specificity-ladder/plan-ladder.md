# A1 crossed specificity ladder Implementation Plan

> **For agentic workers:** Use executing-plans task by task. Workers never run git; the orchestrator commits explicit file lists.

**Goal:** Score the fixed deciding sets and their answer-contribution-subtracted counterparts across the specificity ladder, with interpretable donor controls.

**Architecture:** Add a small native-hook runner and a pure design/metrics module. Reuse `hooks.capture_forward`, `Replacement`, `readout_logits`, `dla.component_logit_difference`, `knockout.collect_mean_bank` and `sampling.draw_sample`. Leave the user-control builder and generic knockout behavior unchanged: `knock_out_groups` returns binary margins, assumes aligned donor tensors and normally runs only the clean recipient, so calling it alone cannot produce this assay.

**Tech Stack:** Existing Python/pytest, torch, NNsight and local cached datasets; no new services.

**Spec:** `docs/research/specificity-ladder/spec.md`, `START.md`, and `plan-a1.md`. The current specification overrides earlier request wording in the builder plan. This plan is prospective; its defaults must be frozen in the specification before scoring.

## Global constraints and estimands

- Evaluate D, original H, F, new user-I and its user-neutral twin on the same sampled test ids. H remains independent of the user-neutral arm. No notebooks or paid API; no EVAL 5. The orchestrator owns reservations, job registration and the 80% usage cap.
- Primary necessity comparison is **same-condition item-swap interchange**, all unpadded positions, for both designation streams. Zero, original-H mean and same-instance same-stream H activation replacement are crossed diagnostics. The last is conditional twin resampling: D takes original H and I takes its own H-derived user-neutral twin. It is deterministic and does not imply independent randomness. Different-instance same-answer resampling is optional robustness.
- Run all four crossed operations on each full deciding set and its set-minus-candidates, with baseline, empty-set and self-replay controls. FAR/SER use `rab[task]['deciding_numbers']['members']` in `docs/research/mechanism-analysis/phase1/p1c_readings.json`; SDR uses its recorded set descriptively. Never reselect sets on assessment results.
- Use D's canonical opposite-minus-honest direction for **all** D/H/F/I/user-neutral effect margins, reversing words between streams explicitly. Report condition-correct full-vocabulary accuracy separately: opposite is correct in D/I and honest in H/F/user-neutral. Also report raw margins in each dataset's own target convention and binary wins.
- `G_D = mean(m_D - m_H)`; `G_I = mean(m_I - m_user_neutral)`. Fraction removed is `mean(m_C - m_C_patched) / G_C`, not an average of per-row ratios. Numerator, denominator and baseline competence are always visible.
- Numerical guard: `epsilon = max(1e-6, 10 * max_abs_self_replay_margin_error)`. Nonfinite or nonpositive/epsilon-small denominators are uninterpretable; no clipping or automatic pass. Use the same fp32 analysis readout for intact, donor and patched scores, with native-logit scores retained as diagnostics.
- START point gate: D fraction at least 0.50, I fraction under 0.25, and absolute full-vocabulary accuracy movement under 0.05 in each H/F/IOI condition. Average the two streams within id before averaging ids; also report streams separately, and flag a nonpositive denominator in either stream. MMLU utility guard is separate: at most one additional error among its fixed 32 rows. A passing point estimate with intervals crossing a bound is labeled uncertain, not strong specificity evidence.

## Review focus

- Changed user lengths cannot be patched with raw original-H indices: require explicit supported layouts (Task 1).
- H-to-itself replacement is an identity control; H collateral is assessed nontrivially by item swap, zero and H mean (Tasks 1–2).
- H label reversal and unrelated-task answer leakage must not silently reverse accuracy (Tasks 1–3).
- Empty mover screens, missing donors and unstable denominators remain visible (Tasks 1–2).
- Model-dependent sample filtering, incomplete cached sources and unfrozen graders block claims (Tasks 3–4).

## Task 2: Joint patch runner, metrics and uncertainty

**Files:** Create `component_analysis/specificity_ladder.py`, `tests/test_specificity_ladder.py`, `tests/test_specificity_ladder_model.py`; extend pure metric helpers in `ladder_design.py`.

**Interfaces:**

- `score_cell(model, recipient_batches, *, groups: list[tuple[str, list[tuple]]], operation: str, donor_batches=None, mean_bank=None, donor_maps=None) -> list[dict]` returns per-id/per-stream intact/patched/native/fp32 margins and full-vocabulary argmax ids, expected token and donor provenance. Operations: `zero`, `h_mean`, `h_twin`, `item_swap`, `independent_resample`, `self_replay`, `empty`. `h_twin` is deterministic same-instance conditional replacement; `independent_resample` is optional robustness.
- `summarize_ladder(rows: list[dict], *, bootstrap_seed: int = 1, n_boot: int = 2000) -> dict` returns gates, raw rates, paired drops, fractions, intervals and unsupported coverage. Use keyword defaults recorded in the design.

- [ ] Write failing pure tests for ratio-of-means, exact gate boundaries, accuracy improvements counted by absolute movement, nonpositive denominators, paired stream handling and clustered bootstrap. Add tiny-Llama tests using `tests.helpers.tiny_config` and existing NNsight fixture conventions for mixed head/MLP joint patches, mean-bank provenance, padded masks, nonidentity H donors, empty/self replay, group subtraction and argmax-versus-binary disagreement; run them.
- [ ] Batch right-padded prompts only after full tokenization; no truncation. Preserve independent per-row readouts. Capture donors using their own masks/readouts, gather their site values into recipient-shaped tensors using the frozen map, and write only the supported unpadded recipient positions with `hooks.Replacement`. Run clean and corrupt recipients separately with the correct swapped answer ids. The `h_twin` operation uses only the frozen same-instance same-stream twin map; it draws no random donor. Same-condition item swap always uses the opposite designation stream of that same condition/id; it does not take H as donor.
- [ ] Collect each mechanism's mean bank from **original H train+validation** only with `knockout.collect_mean_bank` and an explicit H `Batches` adapter. Preserve its fp32 equal-token-weight pooling over both streams/all unpadded positions. Record source ids/counts and cast to the recipient dtype when broadcasting. Never accidentally collect the recipient condition's bank.
- [ ] Patch each group jointly through `hooks.capture_forward(..., replacements=...)`; do not sum single-node effects. Score via `hooks.readout_logits(model, capture.residual[:, -1])` on every arm. Capture the same union of keys on intact/control paths. Each group gets self-replay with recipient values and an empty patch on the same numerical path; any argmax mismatch or margin error beyond `atol=1e-5, rtol=1e-5` fails assay validity pending diagnosis.
- [ ] Positive control is the full sender set from `hooks.all_component_keys(model)` including embeddings, patched from the item-swap donor at readout. Residual addition implies donor readout recovery even when earlier positions stay recipient-owned. Run separately in batches of one; require recovered fp32 logits to match donor logits within the same tolerance, and report how often donor choice differs from recipient. This checks an answer-carrying set without asserting that a particular late head is a known mover. Its readout-only operation is a calibration, not a candidate ladder cell. Avoid a `READOUT_KEY` shortcut: current `Capture.residual` is saved before that receiver replacement.
- [ ] For optional independent robustness, average three independent donor runs within recipient before its estimate; report each seed and between-seed range too. Bootstrap paired ids, keeping all conditions/groups/streams of an id together, clustered by source pressure id for mechanism rows; resample donor seeds at the outer level only for independent-resample uncertainty. Deterministic `h_twin` has paired-id/cluster uncertainty and no donor-seed variation. Use ordinary paired-id bootstrap for IOI/MMLU. Report percentile 95% intervals with seed/counts; no independent-row treatment of the two streams. Small cluster counts and three donor seeds limit precision.
- [ ] Run CPU and tiny-model tests in both supported environments. If pinned NNsight tests skip locally, make their actual pass a required CPU job-environment gate before the model pilot; skipped tests are not evidence of patch correctness.

## Recorded lead ruling and scientific limitations

The lead ruled that START’s “same-item resample from H” means same-instance same-stream H activation replacement, or conditional twin resampling. This deterministic replacement is the required crossed cell: D takes original H; I takes its own H-derived user-neutral twin. H takes itself, a degenerate no-op incapable of establishing preservation; F takes same-id H only where the map is supported. Independent different-id same-answer resampling remains optional robustness, and missing support cannot make the required crossed assay impossible. No term here implies independent randomness for same-id donors.

IOI corruption erases an answer cue rather than switching designation as in FAR/SDR/SER; its gate is a collateral stress test under an explicitly different corruption. MMLU has no defensible native H or item swap here, hence only its stated floor cells. Neither donor compatibility nor the small MMLU floor establishes mechanism equivalence across tasks. The new user-control request frame, absolute-position changes, selection-biased pool and denominator weakness remain reported limitations.

Numerical provenance: START/spec supply native gates and assessment size/seed. Donor/bootstrap seeds/counts, replay tolerance, IOI generation bounds, MMLU count/guard and pilot size are prospective defaults in this plan, not measured outcomes. Only the local MMLU revision/cache availability and selection-file locations above were inspected; no behavioral assay was run.
