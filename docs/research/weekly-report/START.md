# Weekly PI report for the autoresearch workflow

1. **Goal.** Extend the autoresearch workflow with a weekly-report session: one concise, high-level Markdown report
   for the user's weekly PI meeting (Wednesdays, 3 pm Eastern), written from the recorded research state to an
   accepted template, with a brief assembler and a mechanical vocabulary check in the research-session tool.
2. **Directions.** This is a feature, not a research direction: the spec is `spec.md` and the tickets are in
   `issues/`. No GPU jobs and no paid API calls.
3. **What exists.** The accepted template, the plain-name map and the first report (4 November 2026) are in the
   Alignment checkout under `.scratch/weekly-report/` and `project_context/reports/weekly/`.
4. **Exit.** The four tickets are resolved, the tests pass on both interpreters, and the 4 November report passes
   `research-session weekly-check`.
