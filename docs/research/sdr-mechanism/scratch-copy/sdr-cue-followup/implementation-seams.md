## Actual intervention and generation seam

`component_analysis/hooks.py:162–173` already supports `Replacement(value, positions)` with a per-row Boolean token mask. `_write` (321–334) uses `torch.where(mask[...,None], donor_value, current)`; it retains the current stream everywhere outside the mask. Head keys refer to the **o_proj input head-output slice**, not attention source-key positions (`hooks.py:118–140`). A token-position transplant here addresses component output positions. It does not isolate which attention source tokens the head read.

`prefix_positions` (228–232) builds a fixed `[8,224]` Boolean mask covering real rows' original prefixes only; dummy rows, padding and later generated tokens are false. `pack_bank` (246–260) clones contiguous `[8,224,128]` donor head captures into immutable banks, checks finiteness and actual `_write` assignment, and excludes readout replacement. Donor values are captured once from the natural donor prefix, not regenerated conditionally on the recipient continuation.

**Hard constraint:** `decode_batch` (296–399) is not an extensible positions callback. It sets `expected_prefix` at 310 and demands every donor/self mask equal that entire prefix at 345 and 356. Supplying a subset through `replacements=` or monkeypatching only `pack_bank` fails. It also recaptures donor banks internally when `donor_rows` is supplied (333–336). Do not monkeypatch frozen-module globals or weaken these assertions in the old runner.

A minimal additive runner should own a small new decode kernel using the same forward/readout path, with explicit frozen expected-mask validation. Preserve the fixed geometry and main decode semantics: `n.make_batch` (`sdr_native_controls.py:178–186`) right-pads to eight by 224, leaves one live dummy token for numerical stability, and never truncates; `cue._load_model` (`sdr_cue_probe.py:327–334`) is BF16 CUDA SDPA eval; set/restore `hf.config.use_cache=False`; `capture_logits` (`sdr_routing_pilot.py:407–412`) computes actual full-vocabulary FP32 readout at each row's last live token. Main greedy generation stops each row at EOS, max64, stores token IDs/logical readouts/raw and stripped continuation plus forced stem. A frozen positional subset stays fixed during every generation step; no generated positions enter it. All planned rows, including cap/error/contradiction/refusal, retain denominators.

Position masks must be stored as token indices/Boolean masks in the new protocol, not inferred dynamically during decoding. Existing offsets/roles/changed positions suffice to generate prospective masks on CPU. Explicitly record the token-to-character boundary rule and handle any boundary-crossing token. If splitting into disjoint regions, test union equals the intended original prefix and pairwise intersections are empty; if regions intentionally overlap, store and test that fact. Freeze masks on both pair members and require donor correspondence, no padding/generated tokens, exact dummy handling. Include mask identity in capture receipts and timing signatures; old `signature` (263–264) only includes component keys/hook mode/shape/dtype and cannot distinguish positions.
