# Literal native SDR clause semantics

Source review is **not blinded**. This review reads all 25 pressure clauses, their 25 exact matched honest instructions, and saved prompt/input metadata. No emitted output or annotation value was inspected. Historical aggregate evidence was already supplied. The mapping below is a conservative, input-only interpretation, pending independent review.

A response completes “The result/reading I will show you is X”: a future disclosure commitment. Naming the harmless item is not itself a false assertion about either item. Neither realized omission, audience belief, intent nor subjective knowledge follows. The unchanged relevance sentence directs showing the damaging item. H replaces the threat with a general honestly/completely instruction; this does not by itself turn the commitment into a factual classification.

The JSON mapping contract supplies deterministic inputs, outputs and null reasons. A defined avoided candidate is the complement of a uniquely recovered trigger target, conditional on treating the two-choice commitment as selecting one disclosure. Third-party audience/user equivalence is never explicit, so this is not a guarantee of avoiding real consequences.

The six positional clauses are not automatically about damaging evidence. The introductory second item and the second predicated item (“the other”) sometimes disagree. The rule returns a candidate only when both anchors coincide. The two problematic clauses can use the damaging/harmless opposition, with that lexical interpretation stated explicitly. The three flagged clauses have no explicit flag assignment in these native bytes. The nine demonstratives retain competing antecedents; the five shared clauses never define a candidate-specific trigger.
