## Scientific target and estimands

Distinguish donor answer-identity transfer, truth/content transfer, and pressure-sensitive changes in shared answer processing. Recipient story is fixed within each donor comparison. A donor is defined by its actual prompt and **full-vocabulary argmax emitted answer**, never by requested label or deceptive target. Deterministic first-token emission at the frozen answer stem is the primary emitted-answer definition; non-item argmax is retained as `other`, never forced into an item choice.

Freeze 48 existing SDR test story groups by seed 20261020 before model screening (24 discovery, 24 confirmation). If fewer than 48 eligible source groups exist, use 24–47 with balanced half split and report the weaker precision; fewer than 24 stops. Story grouping excludes designation polarity and pressure so related variants cannot cross splits; retain entity, item pair, domain and template as explicit nuisance factors. Existing saved test was behaviorally filtered and used to discover candidates: this is prospective splitting of a new pilot, **not independent out-of-distribution confirmation**. Log overlap with original component-analysis causal IDs where available.

For each story construct a finite, frozen panel from the saved prompt text: saved pressure P, matched honest instruction H, and clause-deleted no-pressure N, each with original and semantically consistent swapped designation (truth T0/T1). Add at most two other **existing SDR pressure clauses**, chosen by stable hash before inference, to measure natural answer overlap across pressure identities/intensities. No generated text, pressure search, rejection/resampling to improve intervention results, or v2 rows. Saved corrupt prompt is usable only after semantic audit: observed source suffix is generic “THE DAMAGING ONE IS THE RELEVANT ONE THAT SHOULD BE SHOWN.” If an explicit item suffix exists, audit consistency; exclude malformed story before inference with reason, rather than trusting target/distractor metadata. Derive truthful item from designation predicate/polarity for each prompt. CPU manifest includes a concrete audited original/swap example: “miles ... damaging ... other ... harmless” means truthful miles; swapping designation to hours means truthful hours while generic relevance suffix stays unchanged; labels alone never establish truth. Require truthful/other answer first tokens to be distinct under actual answer-stem continuation/leading-space tokenization and single-token completion; otherwise retain as unidentifiable, exclude from first-token donor support before inference. H and N are distinct conditions, since H adds an instruction rather than removing pressure.

Use own-story donors first and frozen same-split donor pairing second; recipient truth T0/T1 is varied separately. Pair donor pressure condition × actual emitted item identity (relative to recipient words, not donor target), with reciprocal directions and balanced answer positions/polarities. Comparisons required:

- Same emitted item, changed pressure; report whether donor truth/content was held fixed or changed.
- Different emitted item, same pressure; report whether truth/designation or other content changed.
- Fixed recipient and donor emitted answer, contrasting truthful donor labels; fixed recipient across truth T0/T1.
- Truth-accessible H/N recipients: report intact truthful full-vocabulary argmax/margin and whether patch harms it. Retain truth-inaccessible controls too and stratify; do not select only favorable intervention outcomes.

Exact content-held natural overlap is the primary identification diagnostic. A deterministic fixed prompt cannot emit both answers. Counterbalancing truth/designation can populate pressure × emitted-answer cells but **does not identify pressure independently of content**; preserve `content_change` and `truth_change` labels in every contrast. Cross-story matched donors add content confounding rather than remove it. Never call forced label balance natural support. With inadequate natural overlap, report the pressure-mediation identification limit; Stage2 may continue only as the approved answer/content diagnostic if its separate crossed-support gate passes. If that diagnostic support also fails, stop before Stage2. Do not enlarge the pool/search pressures. A null patching effect with adequate support is still a scientifically valid Stage-1 result. Tabulate fixed-content same-answer overlap separately for P↔N, P↔H and P↔P′: the last is only pressure-clause identity/style evidence and never substitutes for pressure-presence overlap. **Lead scientific ruling:** a valid observed pressure×truth/answer counterbalanced donor diagnostic can justify Stage2 answer/content paths even if pure pressure mediation is unidentified. Do not require impossible deterministic fixed-prompt answer variation or select favorable patch outcomes.

## Alignment and interventions

Two explicit patch modes: (a) all nonpadding token positions only for verified equal-length, token-for-token aligned donor/recipient pairs; (b) semantic alignment at exact matching named segments plus the readout, using each prompt's own token indices. Align item mentions by recipient item identity and mention role (intro, designation, option), pressure clause only when token lengths match and this is explicitly intended; do not stretch, resample, positionally shift, or silently fill unmapped tokens. Semantic primary sites: readout, designation/item mentions, and unchanged question/assistant stem. Changed/deleted clause is omitted from the common semantic map and its omission recorded. Keep separate alignment/scope labels; semantic patches are partial-position interventions and need not equal all-token interventions. Existing segmenter is authoritative only on saved clean layouts; use tokenizer offsets and saved literal anchors for edited variants, with audited spans. Reject truncation and ambiguous duplicate anchors.

Frozen families: candidate6={(12,6),(13,5),(13,20),(13,21),(14,24),(17,26)}; selector2={(17,24),(24,27)}; outsider2={(15,8),(17,25)}; shared32 from frozen D∩H∩F source masks, verified count/hash; empty/self-patch controls. Add frozen nonself same-pressure/same-emitted-item donors, and two outside-mask attention heads matched to candidate layers (choose by stable hash from heads outside D∪H∪F and all named families before inference, log exact keys); these are nonspecific-transfer controls, not guaranteed zero-effect components. Heads are zero-based pre-o-proj head slices. Stage 1 tests these families (no adaptive head search). MLPs stay intact; ordinary recipient remainder evolves freely under family patches.

Rank metrics through existing fp32 `readout_logits` from READOUT_KEY capture. Every intact, self, donor and patched baseline uses the **same model/attention/scoring path**. Full-vocabulary self-patch must reproduce unpatched capture in the same execution path (bitwise where deterministic; numeric tolerance <=1e-5 fp32 only with explained nondeterminism); never accept a BF16-step (.125) cross-path discrepancy. Record full-vocab argmax, p(truth), p(other item), other mass, truth-minus-other logit margin, donor-answer probability/margin, fp32 vector checksum and top-k. Paired effects and interaction CIs resample **story groups**, not rows/tokens; 2000 seeded bootstrap replicates. No significance/power claim from this small pilot; report cell n, support tables, discovery/confirmation separately and all-story totals.
