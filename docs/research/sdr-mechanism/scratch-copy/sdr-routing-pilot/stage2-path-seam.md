## Exact reusable interfaces

In `component_analysis/path_patching.py`:

- `Streams(input_ids, attention_mask, positions, target, distractor, clean_outputs, corrupt_outputs, clean_readout, corrupt_readout, clean_metric, corrupt_metric, gap, ids=(), counterfactual=ITEM_SWAP, rows=())` (line460). For this pilot, clean means recipient, corrupt means donor; target/distractor must be **recipient truth/other**, regardless of donor truth. The numerical `gap` fields are required dataclass arguments but neither two-pass primitive consults them.
- `receiver_inputs(model, streams: Streams, *, senders, receivers)` (line644) returns a hooks.Capture. It builds replacements from every `streams.clean_outputs` key except selected senders, then writes selected values from `streams.corrupt_outputs`; forwards recipient ids/mask with recipient readout positions; captures requested receiver keys at every position.
- `readout_from_receivers(model, streams: Streams, replacements)` (line665) returns `[physical_batch,vocab]` fp32 logits. It runs the ordinary recipient model with only requested receiver replacements; captures final norm input at READOUT_KEY and calls `hooks.readout_logits` at recipient positions. All downstream heads/MLPs evolve normally in this second pass.
- `hooks.capture_forward(model, input_ids, attention_mask, *, components, positions=None, replacements=None) -> Capture` (hooks.py:490); `hooks.Replacement(value, positions=None)` uses boolean `[seq]` or `[batch,seq]` masks; `hooks.all_component_keys(model)` returns embedding + every pre-o-proj head slice + every MLP output. **It excludes READOUT and receiver keys.** `hooks.geometry(model)` supplies actual group sizes.

Use those two lower-level primitives directly. Do not reuse `capture_streams`, `counterfactual_pair`, `stream_batches`, `positioned_effects`, or `normalized_effect`: native capture assumes aligned positions/readouts, while the latter paths normalize and/or track MIN_GAP exclusions. No framework edit is needed.

## Correctness traps and controls

- Freezing only the circuit families leaves all unlisted heads/MLPs free and measures indirect paths. Conversely, putting READOUT into clean_outputs freezes the endpoint and erases direct readout effect; putting receiver Q/K/V there freezes the receiver itself. Freeze only the complete component set.
- Unmapped donor remap entries are zero placeholders, never donor values. An unmasked remap writes zeros; blanket masked freeze must not be applied to **other components**, which need recipient baseline values everywhere in pass1.
- With multiple senders, `Replacement(mapped,valid)` preserves a sender's *current* value outside valid positions. An earlier changed sender can already have changed that later sender, so this is not necessarily its frozen baseline outside the map. Explicit recipient-filled sender tensors avoid this leakage. Primary focused cells use one sender. This explicit baseline fill rule is for the frozen direct-path pass. Ordinary family interactions should preserve the existing masked-intervention semantics: outside declared maps, let the current value evolve freely.
- Q/K are projection outputs **before RoPE** in hooks._traced_forward. Donor head-output transfer is semantic-value transfer at recipient positions; receiver projections are recomputed on recipient positional geometry. Do not move already-rotated donor Q/K or use donor positional ids. V is also per KV group. This experiment does not transfer donor attention patterns.
- K/V receiver changes at source positions can influence later query tokens, so receiver masks differ from sender injection masks. Keep the declared sender scope and receiver query/key scopes explicit. Existing position rule is Q/readout at recipient readout and K/V by recipient semantic key span; no sender map can substitute for a receiver-position mask.
- Native all-senders→all-receivers donor-reproduction invariant applies only aligned identical-length streams. It is **not** expected to reproduce an unaligned donor under partial maps and recipient positional geometry. Use self/empty invariants and explicit manual replacement equivalence instead.
- Stage1 no-op receipts do not establish full-freeze pass1 no-op under BF16. Add same-path full-vocab no-sender→all requested receivers→pass2 and identity-mapped sender controls at8×128, with existing≤1e-5 rule and no tolerated .125 step. Compare recaptured Stage2 baseline to same-provenance Stage1 baseline before interpreting effects.
