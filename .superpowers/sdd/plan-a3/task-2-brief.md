## Task 2: Fit directions, valid nulls and steering baseline

**Files:** `a3_directions.py`, `tests/test_a3_directions.py`, direction stages in `a3_pipeline.py`.

**Interfaces:** `fit_direction(d: Tensor,i: Tensor,h: Tensor,projection: Tensor,*,seed:int,cluster_ids:list[str],instance_ids:list[str]) -> dict`; `random_image_directions(projection: Tensor,*,n:int,seed:int) -> Tensor`; `direction_replacement(z: Tensor,donor: Tensor,direction: dict,*,mode:str,positions:Tensor) -> Tensor`; `select_direction(validation_rows:list[dict],*,sites:list,seed:int) -> dict`.

- [ ] Write failing tests for rank-deficient projection, normalized image vectors, invariant behavior under orthogonal head reparameterization, zero DOM norm, unequal-condition counts, padding, donor-only subspace interchange, secondary centered removal, replay and adjacent-head isolation. Use a small biased toy task where the causal direction is known and a role-only direction is predictive but causally inert.
- [ ] Let `W_h` be the head's `o_proj` column block; use fp32 SVD with relative singular tolerance `1e-6`. Work in orthonormal residual-image coordinates `U`, rank `r<=head_dim`. Fit `v = normalize(mean(W_h z_D)-mean(W_h z_I))` using paired ids, equal stream/id weighting, and train-cluster bootstrap. Use this same singular-value cutoff in the pseudoinverse. Save raw norm, rank, projection spectrum, H center and its pullback `W_h^+v`; zero/unstable norm is not a fitted candidate.
- [ ] Primary interchange in head coordinates is `z' = z + W_h^+ v v^T W_h (z_donor-z)`. Secondary normalized direction removal is `z' = z - W_h^+ v v^T W_h(z-mu_H)`. Thus intervention removes exactly one residual-image direction, along a unit residual-output axis for both learned and null directions. Compute replacement from an intact capture, then replay through the existing inference hooks at readout only. Record finite-precision replay error with the A1 tolerance.
- [ ] Per task/seed choose exactly one site on validation: among candidates whose primary intervention meets all A1 point gates, maximize D fractional removal; if none qualifies choose maximal `D_fraction-I_fraction`, marking validation failure. Lexicographic key resolves ties. No assessment-based joint bundle, alternate site, range or sign choice is allowed.
- [ ] At the chosen site, draw 199 isotropic unit vectors in `U` coordinates, then map through `U`; use RNG seeds `10000+seed`. Do not draw 4096-dimensional ambient vectors. Unit axes do not imply equal realized perturbation energy: report each row's perturbation norm and fit-only projected variance. This is an isotropic-orientation benchmark, not an energy-matched null. Freeze all draws before assessment. Each replicate index comprises the three seeds' null vectors at their respective validation-selected sites.
- [ ] Primary statistic is mean across the three seed fits of D fractional removal, conditional on each fit satisfying every START gate. A nonpassing learned or null fit gives that triplet statistic negative infinity. For a learned triplet to pass, every seed must pass and its statistic must strictly exceed the empirical 95th percentile of 199 null triplet statistics: sort ascending and take index ceil(0.95*199)-1 (zero-based), without interpolation. All comparisons are strict; tied null statistics count against the learned statistic. Save failed-gate negative-infinity counts. Also report unconstrained `D_fraction-I_fraction` and all raw effects so failed-gate nulls cannot hide poor preservation.
- [ ] Freeze exactly two confirmatory hypotheses, `direction_FAR` and `direction_SER`: each selected DOM triplet satisfies every START gate and exceeds the frozen isotropic-orientation null statistic. Compute rank p-value `(1 + count(null_stat >= learned_stat))/200`, with a failed learned triplet assigned p=1. Apply Holm step-down across these two at FWER alpha 0.05: smaller p <=0.025, then larger p <=0.05; stop at the first failure, ties sorted FAR before SER. SDR, nuisance directions, neuron ranges, edges, mask arms and transfers are exploratory/descriptive; their START point gates remain reported but cannot enlarge the confirmatory discovery family. No pooled “some family passed” inferential claim is allowed. These rank probabilities are conditional on the frozen fit/site selection and isotropic-orientation benchmark, not a permutation test of absent deception machinery.
- [ ] Use fixed 2000 paired bootstrap replicates, seed 9001. A pressure cluster is the exact canonical pressure wording, not its task-local integer id; jointly resample an identical wording across FAR/SER and preserve all conditions/streams/seeds/learned/null rows. To retain each task's pressure-stratum count, partition global clusters by task-incidence pattern, resample clusters with replacement within each pattern, and carry all their task-specific ids; weight ids equally within each resampled task. IOI/MMLU use paired prompt-level resampling, shared across seeds/tasks. Treat Holm rejection, strict null percentile, START gates and interval precision as separate outputs.
- [ ] Steering baseline adds `+/- sigma_fit * W_h^+v` at readout, where `sigma_fit` is the train H standard deviation of projection on v. Run both signs without selecting the better assessment sign; the positive sign is preregistered as toward the fitted D mean. Include learned, neutral-frame nuisance direction, and one fixed random steering direction per seed. Report raw rates, margins and collateral rather than treating steering as necessity evidence.
- [ ] Assess the already fitted neutral-frame nuisance direction with the same primary subspace interchange at each validation-selected site and the same controls/three seeds. Include its workload before admission. It cannot select sites or replace DOM. If it too passes the START point gates, emphasize role/framing ambiguity; the defensible conclusion remains D selectivity under these controls, never unique deceptive-intent representation.
- [ ] Implement `simulate_conditional_power(calibration:dict, *, n_rep:int=2000, seed:int=19001) -> dict` with the executable specification below. It uses validation only, after sites freeze, and is conditional on those sites/fit/noise estimates. No assessment outcomes or unconditional discovery-power claim enter it.
- [ ] Add a CPU linear readout probe on the cached head-image coordinates: ridge least-squares labels D=+1/I=-1, regularization 1, intercept unpenalized, train standardization only. Fit on the same eligible train cohort, report validation and fixed-assessment balanced accuracy without model-correct filtering, and compare with the role/length probe. The probe is descriptive separability, never a necessity pass; it cannot select additional sites.
- [ ] Run all direction tests, including tiny-Llama native replay. Pilot all 199 null shapes on a fixed four-id nonassessment validation timing shard before admitting the full panel; this times the exact workload without requiring a full validation null panel for every candidate. Never reduce null count or drop collateral conditions after observing assessment results.

### Executable validation-conditional power specification

- [ ] Cache a calibration panel of 32 null axes at each **selected** task/seed site only, RNG `31000+seed`, on the eligible validation rows and separate validation IOI. Reuse these intact/candidate caches. The 199 assessment nulls remain independently frozen with their original RNG; calibration axes do not replace them. Record actual calibration cost and admit it with the direction inventory.
- [ ] For each seed/task retain each id's intact margins, patched DOM margins, both streams and collateral correctness, plus the 32 null outcomes. Let `delta_C=m_C_intact-m_C_patched`, already averaged over streams within id. Store centered residuals `e_C=delta_C-mean_validation(delta_C)` separately for D and I, and intact `G_D_val/G_I_val`. If either original denominator is nonfinite/nonpositive/epsilon-small, that task's power cell is uninterpretable; never stabilize it by clipping.
- [ ] Grid is the Cartesian product of D fractions `{0,0.25,0.50,0.75,1.00}`, I fractions `{0,0.20}`, collateral loss `{0,0.04}`, applied to both tasks simultaneously. This is 20 shared-effect scenarios. Also run two task-asymmetric scenarios per grid cell: injected D fraction on FAR with SER D fraction 0, and conversely, retaining that cell's I/collateral settings. Report each task's rejection probability and probability of any/both rejections, so Holm and the alternative composition are explicit.
- [ ] Per replicate resample validation pressure clusters with the exact cross-task incidence-pattern bootstrap above; retain original task/cluster/seed linkage. For a resampled id set synthetic learned numerator `delta_D_star=f_D*G_D_val+e_D[id]` and `delta_I_star=f_I*G_I_val+e_I[id]`; synthetic patched margins are intact margins minus these deltas. Compute fractional removal against the **resampled intact** denominators, not the original denominators; preserve their weakness and covariance. Every seed uses its own centered residuals, with the shared cluster draw. This is an additive validation-conditioned noise model, not simulated prompt generation.
- [ ] For H/F/IOI/MMLU correctness start from each row's intact correctness. For condition C with validation intact accuracy `A_C`, assign one Bernoulli loss flag per cluster (IOI/MMLU per prompt) using a deterministic keyed uniform `u[rep,condition,global_cluster]`; the same uniform applies to every seed/task row in that cluster, with the task-specific threshold below, giving correlated rather than necessarily identical flips. A baseline-correct row flips to incorrect iff `u < collateral_loss/A_C`; baseline-incorrect rows stay incorrect. If `A_C=0` and collateral loss is zero, set every flag false; if `A_C < collateral_loss`, mark that cell infeasible. Repeated bootstrap copies get separate occurrence keys shared across tasks/seeds. This gives expected absolute loss of the injected amount, with cluster-correlated flips and no improvements. Preserve margin denominators unchanged. Apply MMLU's fixed-count guard to a separately frozen 32-row **validation-only** utility set, never the A1 assessment rows. If no disjoint cached MMLU validation set exists, power is explicitly conditional on that utility guard passing and cannot claim full-gate power; do not fetch data or borrow assessment rows.
- [ ] For each replicate, resample the 32 cached null-axis indices with replacement to construct 199 null triplet indices, using the same index draw across seeds/tasks and the same pressure/utility resample as the learned candidate. Keep each null axis's **observed validation** patched outcomes unchanged apart from that paired cluster resampling; do not inject learned effects into nulls. Compute the strict quantile, failed-gate counts, rank probabilities and both-task Holm decision exactly as for assessment. This bootstrap expansion approximates the orientation null with 32 calibration axes; report that approximation and binomial Monte Carlo intervals, never finite-199 unconditional discovery power.
- [ ] Report rejection frequencies over 2000 replicates, original/bootstrapped denominator validity, all-seed gate failure frequencies, MC intervals and calibration coverage. An “80-percent detectable D fraction” is the smallest tested fraction with >=0.8 rejection probability for that task/settings and lower tested neighbor below 0.8; otherwise report not bracketed. Add tests for zero-noise known thresholds, weak/negative denominators, cross-task duplicate wording linkage, Holm asymmetric alternatives, exact Bernoulli edge probabilities, fixed RNG reproducibility and calibration-only input rejection.
