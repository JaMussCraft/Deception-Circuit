    --closure-sha256 SHA --payload-pins ddee7e6df8220e06212c56b4bf79e6e5fa659fb2cfd9e4ead1131c164d5456b4 \
    --environment base|mgnp --output FRESH_ABSOLUTE_DIRECTORY

Run inside the pinned Ubuntu SIF, with every declared input on read-only mounts.
The caller must include container startup in its own <=30-second gate. The probe
has a separate 30-second wall alarm from Python entry, a nonrenewing monotonic
subprocess deadline, and strict post-reap deadline checks. Do not retry a failed
compatibility gate automatically. Preserve its output and narrow the closure for
review. The proposal's 89 ELF objects can require 178 bounded readelf/ldd calls;
completion inside 30 seconds has NOT been measured. No runtime is staged here.

Required environment: PYTHONDONTWRITEBYTECODE=1,
PYTEST_DISABLE_PLUGIN_AUTOLOAD=1, OMP_NUM_THREADS=1, OPENBLAS_NUM_THREADS=1,
MKL_NUM_THREADS=1, NUMEXPR_NUM_THREADS=1, CUDA_VISIBLE_DEVICES=''. Do not pass
-S/-s, PYTHONPATH, PYTHONHOME, LD_PRELOAD or LD_LIBRARY_PATH. Normal user-site
startup remains enabled. Preserve required distutils .pth/_distutils_hack bytes.
The probe's output directory is new; an existing output path rejects. Parent
paths must exist and contain no symlinks. The caller owns mount/namespace setup,
actual image invocation, read-only manifest staging and private-parent protection.
